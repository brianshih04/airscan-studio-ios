## Top 5 修復

### Fix 1 — 文件庫改存相對檔名(原 #1,P0)

- 檔案:`Scan/ScanViewModel.swift`
- 問題:文件庫以絕對路徑持久化(`e["url"] = fileURL.path`),iOS container 路徑在 app 更新後改變,`loadDocuments` 的 `fileExists` 全數失敗,歷史文件從清單消失(檔案還在磁碟)。
- 改法:
  - `persistDocuments()` 改存 `lastPathComponent` 到新 key `"file"`。
  - `loadDocuments()` 讀 `"file"` 直接拼接目前 `Documents/Scans`;**migration**:遇到舊 key `"url"`(絕對路徑)取 `lastPathComponent` 重拼目前目錄,掃描檔案照舊救回。
  - 存在性檢查改查重拼後的路徑(`url.path`),不再是失效的舊絕對路徑。

### Fix 2 — PDF 組裝改逐頁 CGPDFContext 串流寫出 + 移出 MainActor(原 #2 + #9,P0 + P1)

- 檔案:`Scan/ScanViewModel.swift`
- 問題:(a) 多頁 PDF 用 `PDFDocument` + `PDFPage(image:)` 把全部頁面解碼圖同時駐留記憶體(50 頁 × 600dpi A4 可達數 GB → jetsam);(b) 整個 ViewModel 是 @MainActor,解碼+編碼+寫檔凍結 UI 數十秒。
- 改法:
  - 新增 `nonisolated static func writePDF(from:to:)`:逐頁 `UIImage(data:)` → 解碼 → `CGPDFContext.beginPDFPage/draw/endPDFPage` → 該頁作用域結束即釋放,記憶體峰值 = 單頁。每頁 mediaBox 設為該頁像素尺寸(點 = 像素,與原本 PDFPage(image:) 行為一致)。
  - 組裝包進 `Task.detached(priority: .userInitiated)` 回傳 `(URL, 頁數)`,`phase = .saving` 之後的解碼/寫檔全部離開主執行緒;單頁 .jpg 路徑一併移入背景。
  - 全部頁面解碼失敗時刪除半成品檔並拋錯(不留 0 頁壞檔入庫)。
- 附帶(原 #12):`pageCount` 改記實際成功寫入的頁數,文件 metadata 與 PDF 內容一致(解碼失敗頁不再被靜默跳過又計入)。

### Fix 3 — 取消/重啟競態加 generation token(原 #3,P1)

- 檔案:`Scan/ScanViewModel.swift`
- 問題:`cancelScan` 把 `scanTask` 清 nil,舊 Task 要等下一個 await 才收到取消;期間新掃描已啟動,舊 Task 收尾寫 `phase = .idle` 蓋掉新掃描狀態,最壞兩個掃描並行、文件重複入庫。
- 改法:
  - 新增 `scanGeneration`,每次 `startScan()` 與 `cancelScan()` 都遞增;`performScan(generation:)` 收尾寫 `phase` 前先驗 `scanGeneration == generation`,過期就不寫(錯誤改 NSLog 丟棄)。
  - `scanTask` 改由 Task 本身收尾時清 nil(`cancelScan` 不再清——否則舊 Task 收尾又把新掃描的 scanTask 清掉)。安全性:`startScan` 以 `scanTask == nil` 為啟動前提,新 Task 只能在舊 Task 收尾後建立,無條件清 nil 不會誤清。

### Fix 4 — ESCLClient.pullPage 補 .completed 終態(原 #4,P1)

- 檔案:`Scan/ESCLClient.swift`
- 問題:HP ADF 掃完最後一頁後 job=Completed、NextDocument 回非 200,但迴圈只認 aborted/canceled,空轉滿 120 輪(~2 分鐘)才回 nil。
- 改法:job 狀態檢查區塊補一條——`phase == .completed && code != 200` 時 NSLog 並 return nil。只動「何時停止輪詢」的判斷,polling 順序、HTTP 呼叫、XML 解析全部未動。

### Fix 5 — OCR 三合一(原 #6 + #7 + #28)

- 檔案:`OCR/OCRService.swift`
- #6 renderer scale:`downsampled()` 改用 `UIGraphicsImageRendererFormat.default()` + `format.scale = 1`,「長邊 4096」不再被螢幕 3x 放大成 ~12288px(~9 倍 bitmap)。
- #7 原子性替換:searchable PDF 原地替換由 `removeItem` + `moveItem` 改為 `FileManager.replaceItemAt(_:withItemAt:)`(失敗時原稿仍在);原檔不存在時退回 `moveItem`(首次寫入情境)。
- #28 刪除未使用參數:`processDocument(at:assumedDPI:languages:)` 移除 `assumedDPI`(全專案無呼叫者傳此參數,呼叫端零改動)。
